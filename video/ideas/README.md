# Video ideas

Ten ready-to-render quizzes per format (100 in total), five cards each. Render one with

```bash
npm run make ideas/<format>/<file>.json
```

It is copied into `quizzes/` and rendered to `out/<slug>.mp4`. Check them all for free with `npm run check -- --ideas`.
